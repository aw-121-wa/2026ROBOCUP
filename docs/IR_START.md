# 红外启动与仓库第三列推算

## 启动

- 固件默认开启完整视觉流程，默认红方；RDK 仍需通电并运行现有桥接服务。
- STM32 上电后自动发送 PING、G0 机械臂就位和 COLOR RED，等待回包；IMU 也必须就绪。
- 就绪后遮挡 PD10 红外至少 100 ms，再放开至少 100 ms，自动解锁并启动全程。
- 就绪前的遮挡/释放不排队发车；若过早操作，请待就绪后重新遮挡再放开。
- 每次 MCU 上电/复位只触发一次。运行中的红外仍用于绕桩，不会再次发车。
- 上位机 ARM/PATH/DISC/FORWARD/SHIFT/RED/BLUE 不再驱动车辆。STOP、PING、RDK_RESET 和遥测保留。
- 下一趟需将车搬回红方起点并复位，再做遮挡/释放。本文未表示已烧录或实车验证。

## 仓库

前两列识别到 1、2、3 中两个不同数字后，最后一列为 `6 - 第一列 - 第二列`。
第二列放球完成后，沿用现有列间距前进 200 mm，停稳后按推算编号放球，不等待第三列识别，也不额外叠加识别后的 25 mm 前进。
第一次未识别时，仍按现有默认 1/2/3 顺序；缺失或重复编号不用于推算。
200 mm 是当前开环列间距，实车需核实第三列停靠位置；推算编号不能纠正前两次识别错误。
